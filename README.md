## 多大带宽才算“大带宽”

一个可以照抄的标准：带宽至少100Mbps，月流量起码1000G，低于这个水平谈不上“大”。

不过“大”在不同地区的难度完全不同。境外商家（香港除外）带宽便宜，很多家1000M共享起步、月流量1T打底，月付一般不超过5美元。香港带宽成本高，三五兆的小水管是常态，能到50M以上就值得叫大带宽。大陆节点成本更高，能给到100M已经算大带宽，千兆套餐多数人只在宣传页见过。

所以判断“值不值”之前先看节点位置。同样标着500Mbps，放在香港和放在洛杉矶，含金量是两回事。

## 下单前先弄清四个概念

这几个概念决定了买到手的东西和想象差多少，值得花两分钟。

**保底带宽。**共享带宽套餐通常会标一个保底值。比如CoalCloud的四川移动无限流量套餐，写法是“最高1000Mbps、200Mbps保底”——峰值能冲到千兆，晚高峰拥挤时最低保障200M。只写“1Gbps大带宽”而不写保底的，默认按共享理解，高峰期能分到多少看运气。

**流量型还是无限流量。**同一家商家经常两种模式并存。云途的深圳电信云服务器就提供二选一：20Mbps无限流量，或1Gbps大带宽流量型。带宽和流量本质是同一份成本的两种分配——无限流量的代价是带宽收窄，流量型的代价是跑超了要加钱。天天跑备份、做下载站的选无限流量；平时闲、偶发高峰的选流量型大带宽更划算。

**独立IP还是NAT。**国内低价大带宽方案大多是NAT：多人共用一个公网IP，每人分一段端口。价格压得低，代价是端口受限、部分协议不好用。要建站、需要固定端口的，下单前必须确认是不是独立IP。

**线路等级。**带宽只是管道粗，线路决定管道通向国内快不快。常见大陆优化线路的大致排序是CN2 GIA > AS9929 > AS4837 > CN2 GT，具体还看本地运营商网络。面向国内用户的服务，线路等级比帶宽数字更值得优先确认。

## 常见问题

**大带宽VPS适合跑什么？**
大文件传输、备份同步、镜像分发、视频转码分发这类对带宽敏感的场景。普通小博客、低并发后台，1-5M带宽都用不满，买大带宽纯属浪费。

**为什么国内大带宽VPS比境外贵？**
国内带宽成本本身就高，100M在大陆已算大带宽。境外很多商家千兆共享起步、月付不到5美元；便宜的大陆千兆方案，通常是靠NAT共享IP和流量计费把成本压下来的。

**香港大带宽VPS需要备案吗？**
不需要。香港节点免备案，物理距离近、延迟低，大陆访问速度接近国内机房，这是香港方案最大的优势。

**月付还是年付划算？**
从各家的促销规则看，折扣基本挂在“新购”上，续费通常回到原价。拿不准商家稳定性就先月付，确定长期用再考虑年付。不管选哪家，数据备份别省。
